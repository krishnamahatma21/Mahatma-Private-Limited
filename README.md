# Mahatma-Private-Limited

Tech Stack: Node.js, Express.js, MongoDB, EJS, Passport.js, HTML, CSS, JavaScript

Developed a full-stack web application that enables users to create, view, edit, and manage business listings with secure authentication and authorization. Implemented user login/signup using Passport.js with session management backed by MongoDB. Integrated category-based listing filters, dynamic routing, and server-side validation using Joi. Designed RESTful APIs, handled CRUD operations efficiently, and followed MVC architecture for clean and scalable code. Implemented flash messaging, error handling, and environment variable security using dotenv.
